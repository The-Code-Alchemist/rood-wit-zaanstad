# Rood Wit Zaanstad

Nieuwe website voor voetbalvereniging **Rood Wit Zaanstad** uit Zaandam.

De website wordt opnieuw opgebouwd als een moderne, snelle en onderhoudbare frontend. Het uitgangspunt is een statische website zonder eigen backend of database, tenzij toekomstige functionaliteit dit noodzakelijk maakt.

---

## 1. Uitgangspunten

Voor dit project hanteren we de volgende uitgangspunten:

- Moderne en responsive website
- Goede gebruikerservaring op desktop, tablet en mobiel
- Schone en begrijpelijke URL-structuur
- Geen WordPress
- Geen eigen backend zolang dit niet noodzakelijk is
- Geen eigen database zolang dit niet noodzakelijk is
- Static Site Generation
- Herbruikbare componenten
- Astro als basis
- React alleen waar interactieve functionaliteit nodig is
- Tailwind CSS voor styling
- Ontwikkeling vanuit IntelliJ IDEA
- Git/GitHub voor versiebeheer
- Eerst een stabiele technische basis, daarna de daadwerkelijke website
